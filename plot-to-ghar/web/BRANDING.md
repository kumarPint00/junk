# Plot to Ghar · Brand and metadata (v2.4.0)

## Name and positioning
- App name: **Plot to Ghar**
- Short description (store): **Track plot purchase, home construction, loans and expenses in one app.**
- Category: Finance / Productivity
- Website: https://plot-to-ghar.vercel.app/
- Android application ID: `com.plottoghar.app` (unchanged for update compatibility)
- Brand colors: navy `#07101e`, mint `#39dcab`, sky blue `#8cd8f2`
- Privacy: Personal financial data must not be advertised or indexed; robots disallow applies to crawling, not authentication.

## Longer store description (draft, not a store submission)
Plot to Ghar helps you manage a plot purchase and a home construction project. Track registry milestones, construction phases and floor budgets. Keep an append-only expense ledger, handle funding, contractor advances, refunds and loan repayments. Log materials and stock consumption, contractor work agreements, scheduled tasks and progress photos. Use reminders and OCR-assisted receipt drafts, then review the extracted details before recording a transaction. Export data regularly to protect locally stored financial records.
